# 密营 · 燎原｜参赛作品包

## 快速运行

1. 解压 ZIP，进入 `web/`。
2. 双击 `index.html` 打开承重结构页面；无需安装依赖或启动服务。
3. `dossier.html` 打开卷宗页面。
4. `sanctuary.html` 打开 3D 故事与场景。该页面需要支持 WebGL 的浏览器；WebXR 头显入口需要兼容设备及安全上下文（HTTPS 或 localhost）。

## 作品文件

- `web/`：离线网页、3D 场景、Three.js 运行库和项目概念图。
- `data/curated/`：整理后的事件、来源、遗址、剧情主张和生成数据。
- `data/schema.event.json`：事件数据结构说明。
- `src/`：数据校验、冲突分析和网页数据构建脚本。
- `docs/作品说明.pdf`：作品方法、数据口径、剧情边界与研究局限。
- `docs/AI使用说明.md`：AI 使用范围与人工复核说明。
- `docs/第三方资源与许可说明.md`：运行库、视觉素材和史料引用说明。
- `docs/视觉与3D建模升级方案_施工级.md`、`docs/视觉升级实施记录_20261019.md`：本轮木刻视觉施工标准与实现范围。
- `submission/`：评审 PPT 与 10 张本轮界面截图。

3D 雪原与被服厂统一为木刻色阶、低面数模型和方向性刻痕；页面按桌面与手机默认不同画质档，并依据浏览器帧时间作单向降级。截图来自 Chromium 软件渲染，只用于展示布局与场景，不代表真机性能或头显验收。

“针线与守望”为 88 秒八幕漫游，单幕时长为 10、12、10、11、10、11、14、10 秒。第 7 幕以无人空台和最后 3 秒静默表现史料留白；第 8 幕的 KL-012 日期分歧是独立证据案例，与被服厂事件无关。

## 运行与复现边界

作品本体是静态文件，ZIP 内已经包含构建好的网页和数据，解压后可直接浏览。`src/` 同时提供数据处理脚本供审查；在 ZIP 副本中重建故事数据或执行 `src/verify_quotes.py` 时，会因缺少 `data/probe_archive/` 来源快照而停止。该目录留在项目 Git 仓库，参赛 ZIP 不复制第三方网页全文。完整构建命令见项目仓库根目录 README 的“构建流程”。

## 重要说明

- 事件库表达公开资料的记载情况，不代表历史事实已经一手档案定谳。
- 3D 场景为程序化艺术示意，不是遗址扫描或历史影像。
- 当前材料未声称完成真实用户测试、实体头显验收或手机真机性能测试。
- AI 辅助概念图仅作视觉示意，不作为史料证据。
