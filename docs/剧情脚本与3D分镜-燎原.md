# 《密营·燎原》剧情脚本与实时 3D 分镜

版本：2026-10-18

定位：东北抗联史料可核查展演；建议成片旁白约 90 秒，网页剧情漫游约 80 秒。

## 故事主线

由今天的整理者打开一条 1931—1945 年的事件时间线，沿着记录追索抗日组织的出现、发展、牺牲与延续；最后回到史料本身，说明哪些信息可以核查、哪些仍有缺口。讲述者是当代整理者，不代替历史人物发言，也不虚构密营生活、战场对白或人物心理。

叙事原则：记载的先后只表示时间顺序；人物并置不表示直接交往或因果；机构数不代表来源独立；地理投影不冒充历史现场；场景光效用于呈现数据，不模拟真实战场。

## 八幕旁白与分镜

## 实时场景与镜头规格

- 以 `web/data.js` 当前事件记录为唯一时间轴；镜头按事件 ID 定位，缺少 ID 时回退到同年份最近记载。
- 琥珀时间光幕沿事件年份移动；事件火光按年份渐次显现，已走过的年份保留低亮度，未到达年份暂时压暗。颜色表达历史数据和叙事层次，不以整屏红色替代抗战精神。
- 程序化顶点/片元着色器绘制火焰粒子、按年份显隐和琥珀平面时间光幕；已走过的火光淡出为余烬效果。普通模式采用平滑轨道补间；减少动态效果偏好下保持静态全景并保留字幕与逐幕亮灯，不自动移动镜头。
- 保留键鼠、触控、2D 证据结构和 WebXR。进入 WebXR 后停止程序运镜，用户用头部转动和手柄移动查看；未用实体头显验收前不宣称真机效果或帧率。
- 字幕、旁白和事实说明使用 DOM 文本层，保证可读、可访问；空间模型只表达时间位置和数据关系，不宣称是历史遗址或战场复原。

## 结尾落版

**核查，是纪念的一种方式。**

每一条记载都能追到来源；每一个尚未确认的关系，都应留在证据之外。

## 补充微观故事焦点：《针线与守望》
