# 《密营 · 燎原》终版方案 v2
## —— 3D + VR 三端形态 · 锐评问题全修复版

> 总纲一句话：**66 条结论是雪原上的 66 座密营灯火，16 个来源是供给火光的烽燧；抽掉一个来源就是一场风雪夜，抽完之后，雪原上还亮着多少火，就是这个库真正的可信度。**

本版吸收锐评全部问题。相对 v1 的关键变化：

| 锐评问题 | v2 解法 | 落点 |
|---|---|---|
| 情感落点为零 | 新增"余烬"尾声 + 火种叙事 | §3 炸点 ⑦ |
| "审问/质证"隐喻风险 | 全套改为 核查所 / 对勘 / 风雪夜 | §1 |
| 检索记录不可自证 | probe 原始存档机制（HTML+截图+时间戳） | §5 |
| 单源占比高、两大来源 | 存档机制同步推进 27 条独占补源 | §6 工期 |
| 程斌叛变没用起来 | 夜袭增加"谁带的队"导演机制 | §3 炸点 ③ |
| 开场黑屏 | 0.5 秒即有画面 + 可跳过 | §3 |
| 移动端缺失 | 三端形态 + 移动特调版 | §2 |
| 无答辩剧本 | 引导式演示模式（guided tour） | §6 |
| sites.json 死数据 | 34 处遗址以真实坐标落为雪原地标 | §4 |
| 数值无仲裁 | 裁决链（学术考订优先级） | §5 |

## 1. 隐喻体系（已去对抗化）

| 旧名 | 新名 | 理由 |
|---|---|---|
| 审问台 | **灯下** | "灯下核查"——对史料负责的姿态，不是对抗 |
| 质证 | **对勘** | 史学本语（校勘学），庄重且准确 |
| 夜袭 | **风雪夜** | 自然意象：不是有人袭击史料，是风暴考验火光 |
| 夜袭模拟 | **风暴试验** | 同上 |
| 抽离/崩塌 | 保留 | 工程术语中性 |

统一话术："我们对每一条记载负责——因为他们的名字值得被准确记住。" 数据逻辑**一字不改**，改的只是姿态。

## 2. 三端形态

```
桌面 3D（主形态）        满配粒子/后期/引导式演示，答辩与评审主入口
移动特调（自动切换）      粒子 20k、去 bloom 保 fog、触控 orbit、竖屏重排
WebXR 沉浸（可选增强）    Quest/Pico 浏览器一键进入，第一人称立于雪原
```

- 检测顺序：WebXR 可用 → 顶部提示"进入沉浸模式"；移动 UA → 自动特调档；其余桌面满配。
- **VR 不是主形态，是上限增强**。理由诚实：评委现场大概率没有头显。VR 的三个真实用途：① 答辩若能带 Quest，现场让评委戴上 60 秒——这是其他队伍绝对没有的瞬间；② 演示视频里录一段第一人称画面；③ 作品链接对任何有头显的人开放。
- 手机陀螺仪全景模式（伪 VR）：不追头部 6DoF，只做陀螺仪环视 + 固定最佳机位，成本一天，覆盖所有手机——**这条才是移动端 VR 的性价比解**。

## 3. 七个炸点（v2，每个 ≤10 秒可被手机拍清）

1. **开场（0.5 秒即有画面）**：首帧就是全景灯火（低配细节），相机运镜后置展开；任意键可跳过。8 秒内完成：俯冲→雪原→灯火按 1931→1945 渐次点亮。
2. **证据流光**：烽燧光索上粒子流向密营，悬停显示引文与检索记录（含"查看原始存档"链接）。
3. **风雪夜（核心炸点，导演制）**：点击烽燧触发风暴试验。新增**导演选择**：普通风暴 / **程斌之夜**——选后者，熄灭的灯火显著更多（程斌叛变→第一路军密营体系暴露→杨靖宇陷入绝境，史实加权在数据里：evt_1938_chengbin_toudi → evt_1940 杨靖宇殉国之间的因果边被点亮），结算面板打真实数字。VR 模式下取消震屏（防晕），改用声场+光变+火光扑面。
4. **重燃**：一键重建，灯火按依赖顺序重新点燃——哪些火靠谁活着，一目了然。
5. **对勘电弧**：多伦 6 月 vs 7 月 12 日的红色电弧在两团火之间跳动——日期分歧第一次有空间形态。
6. **雾墙（负证据）**：雪原边缘未勘探林区，hover 显示"未查：黑龙江省档案馆（闭架）…"——认知的边界看得见。
7. **余烬（情感落点，v2 新增）**："十四年"尾声：相机沿时间轴横扫，1941 年后灯火大片熄灭——镜头最终落在几簇不肯熄灭的残火上，字幕浮现真实数据：

   > **十四年，66 条可核查的记载。其中 29 条在两个以上独立来源中依然对得上。**
   > **他们没有被遗忘。**

   然后全场灯火最后一次齐燃三秒，渐暗，回到主界面。方法论在此收束为铸魂：**核查，是最深的纪念。**

## 4. 空间映射（数据→场景，零新增数据）

| 数据 | 空间表达 |
|---|---|
| `sources[].count / exclusive` | 烽燧火光强度 / 顶部红色警戒灯 |
| `edges` 支撑关系 | 流光索（粒子沿贝塞尔曲线流动） |
| 结论来源数 | 篝火大小：1 源残火摇曳（噪声扰动），多源熊熊 |
| `event_type` | 火光色温（牺牲冷白 / 战斗暖橙 / 会议青色…） |
| `date_variants` 冲突对 | 营间红色电弧 |
| 检索深度 deep/shallow | 烽燧探照扇面宽窄 |
| `not_searched` | 边缘雾墙 |
| **sites.json 34 处遗址** | 雪原地标（真实经纬度 → 场景平面坐标），灰白石碑+地名牌，hover 显示遗址卡——死数据转为地理锚点，并向评委说明"结论不落坐标、遗址落真实坐标"的区别 |
| 程斌因果链 | 风雪夜导演模式专用事件边（暗红） |

## 5. 信息层与可审计性（方法论的地基加固）

- **检索存档机制**：`data/probe_archive/{event_id}/{n}/` 存原始页面 HTML + 截图 + 抓取时间戳；检索浮层加"查看原始存档"入口。评委问"你怎么证明你查过"→ 现场打开存档。负证据从"自述"变"可审计"。
- **数值裁决链**：冲突陈列之外增加裁决标注——孔令波《军事历史》考订口径 > 人民日报表述 > 网络转抄，裁决理由一行话写清。陈列分歧是及格，给出裁决链是优秀。
- **双视图一键切换**：index.html（SVG 对勘底座，原样保留）↔ sanctuary.html（3D 主视觉），共享 data.js。话术："3D 给你看结构，2D 给你看证据。"
- DOM 浮层承担全部考据文字，WebGL 内不放长文。

## 6. 引导式演示（答辩剧本，guided tour）

一键进入，全程自动运镜 + 字幕 + 操作锁定，讲者只管说话：

```
0:00  灯下 → 雪原俯冲（"这是一个可以被核查的数据库"）
0:40  流光 + 悬停（"每一条结论都能追到书名和页码"）
1:20  风雪夜·程斌之夜（"抽掉一个来源，火灭了一片"）
2:20  结算面板（"这就是承重结构，41% 依赖单一年表"）
3:00  对勘电弧 + 雾墙（"分歧和没查过的，我们都摊开"）
3:40  余烬（"十四年，66 条可核查的记载……他们没有被遗忘"）
4:20  切 2D 视图（"3D 看结构，2D 看证据"）
4:40  收束话术
```

同时保留自由模式。**排练两遍，录屏备份**——现场 WebGL 挂了就放录屏。

## 7. 技术选型（v2）

| 项 | 选择 | 说明 |
|---|---|---|
| 引擎 | Three.js r160+（CDN，ES Modules） | 不变 |
| VR | **WebXR Device API + Three.js VRButton** | 浏览器原生，无需上架应用商店；Quest/Pico 内置浏览器直接可用 |
| 后期 | UnrealBloom + 自写雪雾；**VR 会话中自动关闭 bloom**（双目渲染性能） | |
| 地形/火/流光 | 自写 shader + InstancedMesh + Points | 单 draw call 策略不变 |
| 标签 | Canvas 贴图 Sprite（近场才显示）；VR 内用世界空间面板 | |
| 相机 | 桌面自写轨道+关键帧补间；**VR 内禁用脚本运镜**，只允许头动+瞬移（防晕） | |
| 音频 | Web Audio 合成风/火，默认静音，引导式演示里开启；视频用实录环境音 | |
| 降级链 | 桌面满配 → 移动特调 → 陀螺仪全景 → 视频 | 每级自动检测 |

## 8. 性能预算

| 档 | 粒子 | 后期 | 目标 |
|---|---|---|---|
| 桌面高 | 150k | bloom+雾 | 60fps @ GTX1650 |
| 桌面中/自动降档 | 80k | bloom | 60fps @ 核显 |
| 移动特调 | 20k | 无 bloom，fog 代替 | 45fps @ 中端手机 |
| WebXR | 30k + 无后期 | 固定曝光 | 72fps（Quest 2 底线） |

VR 会话裁剪清单：雪粒子减半、流光粒子减半、去电弧、去地形细节、`renderer.xr` 双目 foveated（近密远疏）。连续 3 秒掉帧自动降档并提示。

## 10. 风险与对策（v2）

| 风险 | 对策 |
|---|---|
| 评委现场无 VR 设备 | VR 定位为"上限增强"；视频内录第一人称段；陀螺仪全景兜底 |
| 现场网络不通（CDN 加载失败） | three.js 下载进 `web/vendor/` 本地托管，file:// 也能跑 |
| 低端机卡顿 | 四档降级 + 自动降档 |
| 炫技盖过论证 | 风暴结算强制数字；guided tour 每步带数据字幕；2D 一键可达 |
| 单文件过大 | sanctuary.js + shaders.js + vendor/ 本地化 |
| 交付前时间不够 | 优先级硬排序：补源 > 存档 > 风雪夜 > 余烬 > 运镜 > VR > 打磨 |
