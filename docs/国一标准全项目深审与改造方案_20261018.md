**四、叙事改造：以集体行动为主人公，兼容 88 秒与约 4 分钟**

建议保持《密营·燎原》品牌和《针线与守望》章节名。核心问题：“一处隐蔽的被服厂，怎样承担抗战供给，又怎样在危急时刻转移？”观众是今天的观展者和记录者。历史事实按来源表述，情感由工序、协作与前后落差建立。

以下为待制作脚本结构，共 240 秒；节点阅读计入预算，观众可暂停延长。它是内容设计时长，不是已测试完成时长。

| 幕 / 时长 | 叙事与镜头任务 | 声音、交互与证据 |
|---|---|---|
| 01 工作台 / 18 秒 | 先见布、手与工序，再交代密林中的供给基地。开场 10 秒让观众知道“谁在做什么、为何而做”。 | 一次点击开始，可选择声音或静音；不先报数据库规模。 |
| 02 集体 / 28 秒 | 以裁、理、缝的接续表现集体劳动；成员构成另用短卡呈现。匿名模型不绑定历史人物身份。 | 布料、剪裁拟音建立节律；可展开成员构成对应引文。 |
| 03 一台机器 / 32 秒 | 用机器细节切到手工针脚，让有限条件下的劳动可见。 | 节点一：查看机器与手工两处细节，随后看到原文。“旧机器有记载，具体外形为设计”。 |
| 04 白布与林色 / 30 秒 | 工序匹配剪辑：布料、染制示意、成布。色彩变化要有过程与物理接触。 | 节点二：打开工序标签。树皮种类与用途按引文；锅型、摆位不冒充史料事实。 |
| 05 劳动与组织 / 26 秒 | 从工作间退到桌面，以日期与组织关系简要说明会议事实。避免无依据的座次、决议表演和人物发言。 | 工序声收低，现代讲述者说明；可看会议对应原文。 |
| 06 警讯与转移 / 38 秒 | 以同一机位的台面与布包变化承接离开；只讲来源已载的行动顺序。 | 劳动节律中断；不设生死选择、不画未经证明的撤离路线。 |
| 07 空工作台 / 28 秒 | 回到开场同机位，真实移除人物，呈现空台。改章名为“空下来的工作台”，减少遗物误读。 | 用有来源的陈述与静默承载牺牲；不补“主动掩护”“最后一针”、遗言或心理。 |
| 08 今天的出处 / 40 秒 | 工作台转来源卡，保护复建与合成场景分开说明，观众完成一次准确记忆的行动。 | 节点三：打开机器引文并识别一项视觉推断；返回原幕、继续查证或结束。 |

88 秒模式保留八幕、每幕 11 秒，使用相同 chapter_id、claim_ids 与场景状态。每幕只显示一句主叙事，详情展开。完整导览增加工序、停留与来源任务；打开资料、切到后台均暂停。字幕固定“合成场景”小标，具体边界放在可访问详情，避免每段故事都被说明文字挤满。

短字幕示例：“机器只有一台，衣物主要靠手工缝制。”旁白采用今天的讲述者口吻，不替历史人物发言。结尾可保留“核查，是纪念的一种方式”。革命抗日精神分别由持续劳动、集体协作、组织建设、转移行动和有依据的牺牲记载承载。

历史锚点来自项目现有脚本与[省文旅厅转载报道](https://wlt.hlj.gov.cn/wlt/c114274/202508/c00_31866464.shtml)。报道为二手材料；该事实边界不能因为模型精细而消失。

**五、视觉改造：把预算集中在同一个工作台的三次变化**

视觉记忆点为“正在劳动 → 工序中断 → 空台转出处”。主角可以是集体行动及其物件关系，无需先制作大量全身角色。

| 制作对象 | 先做什么 | 质量门槛 |
|---|---|---|
| 主工作台与旧机器 | 一套可拆节点的重点资产；手、布、针杆等动态部位独立；形制作为设计选型记录 | 尺寸统一，无悬空；轮廓可读，机器不出现现代部件；不使用未经核准的商标和编号 |
| 人物与布料 | 一段可信手工劳动：手触布、布被牵引、针脚渐进；优先局部动作 | 连续 12–15 秒，手、布、桌接触可信；坐姿重量成立，无明显穿模；不靠镜头隐藏主要错误 |
| 主屋局部 | 一处工作空间、前景遮挡和近远层次；未核布局不作精确复原 | 门窗与人物尺度一致；同类物体不靠缩小模型伪造空间距离 |
| 材质与灯光 | 木材磨损方向、布料纤维、铁件粗糙度与环境反射分开制作；建立有预算的接触阴影 | 桌面和手机实机上能辨认木、铁、布；主体与背景分离，亮处有细节，暗处有结构 |
| 镜头 | 建立镜头、劳动中景、细节近景、空景分别设计；使用位置—目标—镜头参数 | 针脚近景真正可达；手机不裁掉手和机器；减少无意义持续绕转 |
| 声音 | 现代旁白、连续工序拟音、少量环境声；关键处留静默 | 静音仍可理解，旁白清楚，章节切换不重叠或断句；素材可追溯 |

建议先完成 12–15 秒实时样片，艺术方向选择“写实材质与克制的概括造型”，让概念图和最终场景接受同一标准。样片不通过接触、姿态、构图检查，不扩建院落。用当前程序资产保留低档和失败退路；高质量资产逐个替换。

渲染实施顺序：比例与支撑 → 可读动作 → 构图 → 材质 → 主辅光与接触阴影 → 有预算的后期。当前增加 bloom、粒子或雾密度，无法修复劳动和物体接触问题。

**六、数据与工程改造：先建立契约，继续静态交付**

当前是 Python 离线数据管线和静态 Web，没有业务后端。此次升级继续使用这一结构。多人在线审校、权限和持久化注释如成为真实需求，再设计服务；当下的数据正确性与离线展示可直接在现有结构内解决。

目标关系：`文档 → 原文片段 → 原子主张 → 章节/卷宗/图形`。每个层级具有稳定 ID，显示名不充当外键。

| 层 | 必要字段与语义 | 构建检查 |
|---|---|---|
| document/source | source_id、机构、标题、日期、URL、快照状态、版本/哈希、材料类型 | 文档存在性、链接类型、快照能否打开；转载关系不自动等于独立史源 |
| quote | quote_id、source_id、逐字引文、网页段落/纸本页码 | 引文与原文位置可对照；编辑解释不能写进原文 |
| claim | claim_id、主体、动作谓词、值类型、数值/日期区间、精度、quote_ids、支持范围 | 外键无悬空；负伤与牺牲分开；日期与数值类型分开；未载与反对分开 |
| interpretation | 编辑判断、支持引文、推理步骤、审阅状态、反例/未决项 | 未核判断不能进入“采纳值”；有来源也只能证明来源实际支持的范围 |
| chapter | chapter_id、claim_ids、短字幕、长正文、镜头、声音、交互、可视设计说明 | 88 秒与完整导览共享事实；章号、引用、状态必须可回跳 |
| issue | 字段、动作、参与主张、可比性、严重度、处理状态 | 日期/数值分歧统一进入所有视图；枚举一致 |

具体实施：

1. 冲刺版先为主故事建最小主张集，为现有日期来源加稳定映射；保留旧 ID 和迁移记录。全量 66 条主张化安排在下一阶段。
2. 整体构建分为“从 curated 再导出”和“完整来源重建”；所有正式写入先到 staging，失败不覆盖。当前旧 XLSX 不作为完整重建输入。
3. 为 cases/data/structures 设置 schema_version、build_id、输入哈希和计数摘要；发布同时生成，避免视图各读一份过期裁决。
4. 只为高风险规则建立必要回归样例：年份相合但月日不同、月区间与日点、同人不同动作、引文未载年份、日期外键失配、坏行导入、空数据、长中文。以语义正确为断言，避免只验证实现本身。
5. 3D 拆为场景、输入、章节时钟、资料面板与 XR 的小模块；先确立显式 mode/input/playback 状态，再逐段拆出，保持每次可回滚。避免临期同时迁移框架、引擎大版本和数据全模型。
6. 普通浏览的固定详情与 XR 卡片共用同一来源数据，显示组件分开；隐藏对象不参与射线检测，工厂只使用自己的地面与对象集。

资产引入 GLB 后，正式 3D 以本地 HTTP 服务或 HTTPS 运行；不要沿用“2D 数据脚本可 file:// 打开”去承诺全部模型加载路径。启动器、端口占用提示、相对路径和离线资源需随交付验收。
