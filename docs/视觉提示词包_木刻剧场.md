## 一、风格总纲（先跑这一条，定基准图）

**中文版**

```
东北抗联密营被服厂，木刻版画风格的剧场式三维场景。

视觉语言：1930 年代中国左翼木刻运动 + 北大荒版画的刀痕肌理，高对比、硬边缘、块面化。
色彩：严格五阶灰——近黑 #0A0C0B、深灰 #1C211E、中灰 #3A423C、浅灰 #8A9086、纸白 #E8E2D4；
全画面只允许一个彩色：琥珀色 #D08A3E（灯火、缝纫机金属、针脚）。
光照：单一硬光源从画面左上 45° 侧逆打来，允许过曝到纯白、允许阴影全黑，不要柔和渐变。
主体：木刻楞房屋的深色剪影占据画面右侧三分之一，前景有树枝或蒸汽遮挡，中景是工作台与手。
质感：全画面叠加纸纹与刀刻颗粒（透明度 8%），表面无高光反射，呈哑光纸面质感。
构图：主体偏离画面中心，一条引导线（桌沿或光束）从左下引向主体，景深靠雾分三层。
氛围：寒冷、安静、克制，有历史档案的重量感，不是恐怖也不是悲壮。
```

**English**

```
A woodcut-print theatrical 3D scene of an anti-Japanese guerrilla supply factory in the forests of northeast China, 1936.

Visual language: 1930s Chinese leftist woodcut movement + Beidahuang printmaking — carved gouge marks, hard edges, blocky planes.
Palette: strictly five tones — near-black #0A0C0B, dark grey #1C211E, mid grey #3A423C, light grey #8A9086, paper white #E8E2D4.
Only ONE color allowed: amber #D08A3E (lamp light, sewing machine metal, needle stitches).
Lighting: single hard key light from upper-left 45° backlight; allow blowout to pure white and shadows to pure black; no soft gradients.
Subject: dark silhouette of a log cabin filling the right third; foreground occluded by branches or steam; midground is a workbench with hands.
Texture: overlay paper grain and carving scratches (8% opacity); matte paper surface, no specular highlights.
Composition: subject off-center, a leading line (table edge or light beam) from lower-left toward the subject, depth separated by three fog layers.
Mood: cold, quiet, restrained, the weight of an archival document — not horror, not heroic.
```

## 二、八幕分镜（逐条生成概念图）

> 每条都在总纲基础上追加；建议先出一张总纲基准图，后续用"same style"续接。

### 第 1 幕 · 一笔账（10s）
```
【追加】雪原上一件摊开的军衣，剪影式呈现，衣领与袖口有缝补痕迹；远处是被雪压弯的针叶林剪影。
画面中只有军衣边缘被琥珀色光勾出一道亮边。极简，大面积留白（纸白与近黑各半）。
```
```
[append] A single military winter coat laid open on snow, rendered as silhouette; visible mends at collar and cuffs;
distant spruce forest bowed by snow. Only the coat's edge catches a thin amber rim light. Minimal, half paper-white, half near-black.
```

### 第 2 幕 · 三个人名 + 十三双手（12s）
```
【追加】俯视工作台，四组前臂与手从画面四边伸入，手指在布面上推针；手部保留指节与指甲的细节（手是画面唯一"真实"的部分），
手臂以下渐隐入黑色。桌面铺开的粗布呈中灰，针脚是细密的白线。逆光，手掌边缘透亮。
```
```
[append] Top-down workbench: four pairs of forearms and hands enter from the frame edges, fingers pushing a needle through cloth.
Hands keep knuckle and nail detail (the only "real" element); arms fade into black below the elbow.
Coarse cloth in mid-grey, stitches as fine white lines. Backlit, palm edges glowing translucent.
```

### 第 3 幕 · 唯一一台机器（10s）
```
【追加】微距：旧缝纫机的针杆与压脚，金属是画面唯一有反光的材质（哑光金属，只在高光处一点琥珀）。
针尖正刺入布面，布纤维被顶起的瞬间。景深极浅，背景全黑。
```
```
[append] Macro: the needle bar and presser foot of an old sewing machine; metal is the only reflective surface (matte metal, amber only at the highlight).
The needle pierces cloth, fibers lifting at the point of contact. Extremely shallow depth of field, background pure black.
```

### 第 4 幕 · 树皮熬出的颜色（11s）
```
【追加】铁锅上方升起蒸汽（唯一的柔边元素，其余全部硬边）；锅中液体是浑浊的黄绿色，水面映出一点琥珀火光。
锅沿与木柴是深色剪影。蒸汽在逆光中呈半透明纸白。
```
```
[append] Steam rising from an iron cauldron (the only soft-edged element; everything else hard-edged);
liquid inside is murky yellow-green, water surface reflecting a fleck of amber firelight.
Cauldron rim and firewood as dark silhouettes. Steam translucent paper-white against backlight.
```

### 第 5 幕 · 同一张桌子，换了一件事（10s）
```
【追加】同一张木桌，布被推到一边，桌上摊开一张纸与一支铅笔；纸面是画面中最亮的一块（纸白），
上面有手写的字迹但不可辨认。灯从上方打下，纸的边缘锐利如刀切。
```
```
[append] The same wooden table, cloth pushed aside; a sheet of paper and a pencil laid out.
The paper is the brightest area in frame (paper white), with illegible handwriting.
Lamp light from above; the paper's edge is sharp as a knife cut.
```

### 第 6 幕 · 阎把头报信，陈静山下令（11s）
```
【追加】雪地上的脚印从画面右下延伸向远处的密林，两行，一深一浅；近处是半开的木门，门内一片黑。
远处有极小的两个人影（剪影，无细节）。雪面是浅灰，脚印是深灰。
```
```
[append] Footprints in snow leading from lower-right toward distant forest — two trails, one deeper;
a half-open wooden door in the foreground, blackness inside. Two tiny silhouettes far away (no detail).
Snow surface light grey, footprints dark grey.
```

### 第 7 幕 · 小把头留下（14s，空台 3 秒）
```
【追加】空的工作台，桌面上什么都没有（连布都收走了）；门口一束光斜切进来，落在地面形成一块亮区，
亮区里没有任何东西。整个画面只有一个光源、一块亮区、一片空。
```
```
[append] An empty workbench, nothing on it (even the cloth is gone); a shaft of light from the doorway cuts diagonally onto the floor,
forming a bright patch with nothing in it. One light source, one bright patch, one emptiness.
```

### 第 8 幕 · 遗址与三种记载（10s）
```
【追加】复建后的院落全景（仍是木刻风），画面前景叠加三张半透明的纸片剪影，纸上各有一行日期，
纸片呈纸白，微微错位。院落是深灰剪影，天空是纸白。
```
```
[append] Wide shot of the reconstructed compound (still woodcut style); three translucent paper-slip silhouettes overlaid in the foreground,
each with a single line of dates, paper-white and slightly offset. Compound as dark grey silhouette, sky paper-white.
```

## 三、贴图与肌理（生成后用于 3D）

### 3.1 木刻木纹（`timber`）
```
无缝平铺的木刻木纹，深灰底 #3A423C，刀刻线条沿木纹方向，线宽 2-4px，黑白对比强烈，
无高光、无渐变、无照片质感。512×512，可平铺。
```
```
Seamless tiling woodcut wood grain, base #3A423C, gouge lines along the grain, 2-4px width, high contrast,
no specular, no gradient, no photographic texture. 512×512, tileable.
```

### 3.2 粗布（`cloth`）
```
无缝平铺的粗麻布木刻肌理，中灰 #8A9086，经纬线用断续的刻痕表现，偶尔有白色高光点（线头），
整体哑光。512×512，可平铺。
```
```
Seamless tiling coarse linen in woodcut style, base #8A9086, warp and weft as broken carved lines, occasional white flecks (loose threads),
fully matte. 512×512, tileable.
```

### 3.3 纸纹叠加（全屏）
```
极细的宣纸/牛皮纸纤维纹理，透明背景，只有纤维与颗粒，黑白色，用于叠加在画面上，
不能有任何图案或色块。1024×1024，可平铺。
```
```
Very fine rice-paper / kraft-paper fiber texture, transparent background, only fibers and grain, black and white,
for overlay compositing. No patterns, no color blocks. 1024×1024, tileable.
```

## 四、3D 改造提示词（给写代码的 AI）

```
项目：Three.js r150（UMD，file:// 可用）纯静态 3D 场景，文件 web/sanctuary.js（约 100KB，单文件）。
目标：把当前"想写实但写不实"的 PBR 场景，改造为"木刻版画剧场"风格。不要重写架构，只改材质、光照、后处理、构图。

一、材质（替换 const FM = {...} 的全部 16 个材质）
1. 全部改为 MeshLambertMaterial 或 MeshBasicMaterial + 顶点色，不要 MeshStandardMaterial（省性能、去高光）。
2. 颜色只用五阶：#0A0C0B / #1C211E / #3A423C / #8A9086 / #E8E2D4。
3. 唯一彩色 #D08A3E，只给：灯火（glow）、铁器高光（iron）、针脚（stitch）。
4. 木纹/布纹贴图保留，但作为 map 且 color 置白，让贴图承担明暗；关闭 bumpMap（Lambert 不支持）。

二、光照
1. 删除 AmbientLight 与 warmFill，只保留一个 DirectionalLight 作为主光：
   方向 (-0.6, 0.75, 0.3)（左上侧逆），强度 1.6，颜色 #FFF2DC。
2. 增加一盏 PointLight 作为灯火：位置同现有 lamp，强度 2.2，距离 12，衰减 2，颜色 #D08A3E。
3. 开启 renderer.shadowMap.enabled = true，类型 PCFSoftShadowMap；
   主光 castShadow = true，shadow.mapSize 1024，shadow.camera 范围覆盖 ±20；
   地面、桌面、房屋 receiveShadow = true，人物与机器 castShadow = true。
4. 环境光用极低强度的半球光替代（HemisphereLight，天空 #1C211E，地面 #0A0C0B，强度 0.25），只用来防止全黑。

三、后处理（若无 postprocessing 依赖，用 CSS 叠加替代）
1. 纸纹叠加：在 canvas 上层加一个 div，background-image 为纸纹 PNG，mix-blend-mode: screen，opacity 0.08，pointer-events: none。
2. 暗角：同一层叠加 radial-gradient（transparent 55% → rgba(10,12,11,0.55) 100%）。
3. 不要加 bloom（木刻风不需要），不要加 DOF（用雾分层代替）。

四、雾与空间分层
1. 保留 FogExp2，密度按模式调：factory 0.018（比现在 0.013 更浓），让背景树木退成剪影。
2. 背景色 #0A0C0B（近黑），不要有天空渐变。

五、构图（改每幕 camera 的 theta/phi/radius/target）
规则：①主体偏离中心 ②必须有前景遮挡 ③一条引导线。
八幕建议值（theta, phi, radius, targetX, targetZ, targetY）：
 1: (0.18, 1.30, 14, 0.4, -3.2, 1.9)
 2: (0.10, 1.18, 4.2, -0.1, 0.25, 1.55)
 3: (0.10, 1.40, 2.4, 0.30, -0.18, 1.45)
 4: (0.42, 1.36, 4.2, 0.85, -0.15, 1.62)
 5: (-0.18, 1.30, 7.5, 0.1, -0.6, 1.62)
 6: (0.14, 1.22, 12, 1.4, -2.6, 1.95)
 7: (0.10, 1.16, 15, 0.2, -2.6, 2.05)
 8: (-0.26, 1.30, 19, 0.2, -3.4, 2.05)

六、人物
1. 人物改为剪影：删除 skin / hair 材质，头部与躯干统一用 #0A0C0B，不建五官（删掉眼睛、鼻子、嘴的 fSphere 调用）。
2. 手部保留：手掌与手指仍用 #8A9086，保留指节细节——"手是人，身体是符号"。
3. 阴影方向必须与主光一致（人物脚下投影朝右下）。

七、验收
1. 截图直方图应集中在 5 个亮度峰，无中间灰大面积堆积。
2. 任一帧截图中，琥珀色像素占比 < 5%。
3. 第 7 幕空台：桌面上无任何物体，只有门口一束光。
4. 手机（390×844）帧率不低于当前版本（因为关了 PBR 与 bump，应更快）。
```

## 六、使用建议

1. **先生成总纲图**，确认风格后再批量出八幕——否则八张风格不统一。
2. 八幕的追加段可以直接接在总纲后面用逗号连接，也可以作为"续接"指令。
3. 3D 改造提示词里第六节（人物剪影）风险最高，建议先改一幕试效果，别一次全改。
4. 色值不要改：五阶灰 + 一个琥珀是这个方案的全部骨架，改了就不成立。
