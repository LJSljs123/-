## 五、验收标准（Claude 检查 Luna 产出时逐条核对）

1. **不破坏铁律**：禁止硬编码路径；前端纯静态；`build_*.py` 重建后数字不回退（校验问题 0）
2. **数字一律脚本生成**：任何新页面/新文案不得手填 66/33/56 等指标
3. **视觉红线**：灯火/烽燧/遗址不编坐标、不编数据；单源警示文案保留
4. **性能**：3D 在中端核显 60fps（改动后需附 FPS 或粒子数说明）
5. **回滚可行**：改动前有 git 提交， Luna 自检含 `git diff --stat` 摘要
6. **文案口径**：灯下/对勘/风雪夜（不用旧隐喻词）；"他们没有被忘记"级情感句须有数据支撑
