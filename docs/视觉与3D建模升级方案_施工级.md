# 视觉与 3D 建模升级方案（施工级）

审查基线：`39e5d06 feat: upgrade story experience to woodcut theater`
性质：在木刻剧场已落地的基础上，给出"从 60% 到 90%"的施工方案。

---

## 一、审查：木刻已落地，但只落了一半

`39e5d06` 做了五件事，做得对：

| 已落地 | 证据 |
|---|---|
| 材质换 Lambert | `FM` 全表 MeshLambertMaterial，颜色收成五阶灰 |
| 唯一彩色 | `glow` 用 MeshBasicMaterial `0xd08a3e` |
| 单主光 + 阴影 | `factoryKeyLight` 方向光 castShadow、1024 阴影贴图、桌面/工人/机器投影 |
| 纸纹 + 暗角 | `factoryGrain` 用 canvas 程序生成，叠在画布上 |
| 人物剪影 | `coat 0x1c211e` / `coatAlt 0x0a0c0b`，手 `hand 0x8a9086` |
| 三关任务 | 新增 `web/story-trail.js`，localStorage 记三关，完成后出「你已看完三种记载、一处分歧，并把结论留在证据边界内」 |

但四件事没做，导致**画面还是"圆润的灰"，不是"木刻"**：

### 1.1 没有 `flatShading`——这是木刻的开关

```
grep flatShading web/sanctuary.js → 只有 2 处（雪原树干、地形）
FM 全表 17 个材质，0 个开 flatShading
```

Lambert 是逐顶点插值的，球体开了 Lambert 仍然**光滑**。木刻的块面感来自**每个面独立法线**——必须 `flatShading: true`。

现在的效果：材质颜色对了，但形体还是"圆球"，像"上了灰的水泥球"。

### 1.2 几何面数太高

`fSphere(..., 20)`、`(..., 16)`、`fCylinder(..., 14)`——一个头 20 段、一根木头 14 边。

木刻风应该 **6–8 段**：多面体的硬转折才是刀刻的块面。20 段 + flatShading 会产生"低模但面太多"的塑料感，只有 6–8 段才有"刻出来"的味道。

### 1.3 雪原模式完全没改——而它是主入口

```
6 处 MeshStandardMaterial：terrainMesh、树、叶片、树干、灯火、烽燧
雪原光照仍是 moon(0xa8b9b6) + warmFill(0xa27a52)
```

用户点开 3D 第一眼看到的是**雪原**（66 灯火 / 33 烽燧），那是旧 PBR 灰绿风；进被服厂故事才变成木刻风。**同一个作品两套视觉语言，切换时像换了两个作品。**

### 1.4 纸纹不是刀痕

`grainCanvas` 是 192×192 的随机噪点，放大后是"颗粒"，读作胶片感，不是木刻。

木刻的灵魂是**方向性刻痕**：刀沿一个方向走，留下长线、断口、白边。噪点没有方向，所以不"木"。

### 1.5 另外两处技术冲突

| 问题 | 说明 |
|---|---|
| `ACESFilmicToneMapping` | ACES 的设计目标是把高光压成柔和灰白（电影感）。木刻要的是**纯白到纯黑的硬切**。两者直接冲突 |
| 无前景遮挡 | 构图三件套（前景/偏离中心/引导线）只做了后两项，没有一根树枝、一缕蒸汽挡在镜头前 |

## 二、完整视觉系统（设计令牌）

### 2.1 色板（六级，不可增减）

| 令牌 | 色值 | 用途 | 占比 |
|---|---|---|---|
| `ink` | `#0A0C0B` | 剪影、最深阴影、天空 | 35–45% |
| `soot` | `#1C211E` | 深块面（屋顶、衣、树干） | 20–25% |
| `ash` | `#3A423C` | 中灰（桌面、布、墙） | 15–20% |
| `dust` | `#8A9086` | 浅灰（雪、手、纸背） | 8–12% |
| `paper` | `#E8E2D4` | 纸白（高光、纸、蒸汽） | 3–5% |
| `ember` | `#D08A3E` | **唯一彩色**（灯火、铁器高光、针脚） | < 3% |

**铁律**：任何一帧截图，`ember` 像素占比不得超过 5%，`paper` 不超过 8%。超过就是"亮了"，不是木刻。

### 2.2 材质矩阵（9 种，覆盖全部物体）

| 名称 | 颜色 | flatShading | 贴图 | 用在哪 |
|---|---|---|---|---|
| `mat.ink` | ink | ✅ | — | 人物身体、地面、远景树 |
| `mat.soot` | soot | ✅ | 木纹 | 房屋、家具、机器外壳 |
| `mat.ash` | ash | ✅ | 布纹 | 桌面、布料、雪堆 |
| `mat.dust` | dust | ✅ | 布纹 | 手、纸、雪面 |
| `mat.paper` | paper | ✅ | — | 高光面、蒸汽、纸 |
| `mat.ember` | ember | ❌ | — | 灯火（Basic，不受光） |
| `mat.iron` | soot | ✅ | — | 铁器（唯一有边缘高光的） |
| `mat.cloth` | ash | ✅ | 布纹（强） | 军衣、被褥 |
| `mat.glass` | paper | ❌ | — | 窗纸（半透，opacity 0.4） |

**关键**：全部 `flatShading: true`（`ember` 与 `glass` 除外）。

### 2.3 光照（三套场景，同一逻辑）

统一逻辑：**一盏主光定方向 + 一盏火光定焦点 + 半球光防全黑**。

| 场景 | 主光 | 火光 | 半球光 | 阴影 |
|---|---|---|---|---|
| 工厂 | Directional `#FFF2DC` 1.6，左上侧逆 | Point `#D08A3E` 2.2，灯下 | `#1C211E/#0A0C0B` 0.25 | ✅ 1024 |
| 雪原（待改） | Directional `#C9D2CC` 1.2，右上高位 | 66 盏 Point `#D08A3E` 0.8（合并为 8 盏代表） | 同上 0.2 | ❌（远景不投影，省性能） |
| 余烬 | Directional `#8A6A48` 0.8，低角度 | 同上 1.4 | 同上 0.3 | ❌ |

**雪原 66 盏 PointLight 是性能杀手**——现在 66 个点光源每帧都要算。改为：8 盏真实 PointLight（选取分布均匀的 8 个）+ 其余 58 个只用 `mat.ember` 自发光，不参与光照计算。视觉几乎无差，帧率能翻倍。

### 2.4 后处理链（顺序不能错）

```
1. 渲染到 canvas（tone mapping = NoToneMapping）
2. 叠刀痕层（mix-blend-mode: multiply，opacity 0.10）
3. 叠纸纹层（mix-blend-mode: screen，opacity 0.06）
4. 叠暗角（radial-gradient，transparent 52% → rgba(10,12,11,.6)）
5. 可选：叠一层极轻的"印刷错位"（同一 canvas 复制一份，偏移 1px，opacity 0.04，mix-blend-mode: multiply）
```

第 5 步是木刻/版画的秘密武器——真实的套色版画会有 0.5–1px 的套印偏差，这一层能让画面瞬间"像印出来的"而不是"渲染出来的"。成本几乎为零。

## 三、3D 建模规范（几何语言）

### 3.1 面数预算（这是木刻风的核心）

| 物体 | 现在 | 目标 | 说明 |
|---|---|---|---|
| 头 | Sphere 20 段 | **Icosahedron(1)** 或 Sphere 6 段 | 20 段是圆球，6 段是"刻出来的头" |
| 躯干 | Sphere 20 段 | Cylinder 6 边 | 块面 |
| 手臂 | Link 10 段 | Cylinder 5 边 | 硬转折 |
| 手指 | Link 5 段 | Box 或 Cylinder 4 边 | 现在 5 段太圆 |
| 木头（房屋） | Cylinder 14 边 | **Cylinder 7 边** | 七边形木刻楞，每面一个块 |
| 桌面 | Box | Box（不变） | ✅ |
| 树 | 程序锥体 | 保留，但减到 6 边 | |

**判断标准**：远看是剪影，近看能数清块面。数不清 = 面太多；棱角太尖 = 面太少。

### 3.2 比例系统（现在比例是错的）

实测：人物身高 3.2 单位、桌面 1.41、椅子面 0.56。
换算成真人尺度：人物 1.75m 时，桌面 = 0.77m（✅ 合理），椅子 = 0.31m（❌ 太矮，应该是 0.45m）。

**建立基准**：1 单位 = 0.55m（人物 3.2 单位 ≈ 1.76m）。据此校准：
- 桌面 0.75m → 1.36 单位（现在 1.41，接近，微调）
- 椅面 0.45m → 0.82 单位（现在 0.56，**偏低 0.26**）
- 门高 1.9m → 3.45 单位
- 缝纫机台面 0.72m → 1.31 单位

### 3.3 LOD（性能分级）

| 级别 | 触发 | 策略 |
|---|---|---|
| 高 | 桌面、故事模式 | 全部细节，阴影 1024 |
| 中 | 手机 | 阴影 512、关掉纸纹叠层、树减半 |
| 低 | 低端机（FPS < 30 持续 2 秒） | 关阴影、关刀痕、灯火只留 8 盏 |

自动降级：`performance.now()` 采样 60 帧，p95 帧时间 > 33ms 就降一级，只降不升（避免抖动）。

## 五、关键技术实现

### 5.1 flatShading 的正确开法

```js
// 错：给材质加 flatShading，但几何是共享顶点的（BufferGeometry 默认 index 化）
new THREE.MeshLambertMaterial({ color: 0x1c211e, flatShading: true })

// 对：flatShading 需要几何非索引化，Three.js 会自动处理，
// 但要确保几何没有 smooth normals——SphereGeometry 默认就是 smooth
// 所以：材质加 flatShading + 降低段数（段数高时 flatShading 会产生碎面）
```

**实测建议**：球体 6 段 + flatShading = 清晰的二十面体块面；球体 20 段 + flatShading = 密集碎面，更难看。**必须同时降段数**。

### 5.2 刀痕生成算法（替换现在的噪点）

```js
function knifeTexture(size = 512, angle = 0.26) {
  const c = document.createElement('canvas');
  c.width = c.height = size;
  const ctx = c.getContext('2d');
  ctx.fillStyle = '#E8E2D4';           // 纸白底
  ctx.fillRect(0, 0, size, size);
  ctx.save();
  ctx.translate(size / 2, size / 2);
  ctx.rotate(angle);                    // 主方向
  ctx.translate(-size, -size);
  // 主刻痕：长线 + 断口
  for (let i = 0; i < 320; i++) {
    const y = Math.random() * size * 2;
    const x0 = Math.random() * size;
    const len = 40 + Math.random() * 120;
    const gapStart = x0 + Math.random() * len * 0.5;
    const gapLen = 4 + Math.random() * 16;
    ctx.strokeStyle = Math.random() > 0.72
      ? 'rgba(28,33,30,.22)'            // 深痕（凹）
      : 'rgba(232,226,212,.55)';        // 浅痕（刀白边）
    ctx.lineWidth = 0.8 + Math.random() * 1.4;
    // 两段，中间留断口——断口是木刻的特征
    ctx.beginPath(); ctx.moveTo(x0, y); ctx.lineTo(gapStart, y); ctx.stroke();
    ctx.beginPath(); ctx.moveTo(gapStart + gapLen, y); ctx.lineTo(x0 + len, y); ctx.stroke();
  }
  ctx.restore();
  // 次要方向：交叉 2 组，透明度更低
  ['0.9', '-0.6'].forEach(a => {
    ctx.save(); ctx.translate(size/2, size/2); ctx.rotate(parseFloat(a));
    ctx.translate(-size,-size);
    for (let i = 0; i < 90; i++) {
      const y = Math.random() * size * 2;
      ctx.strokeStyle = 'rgba(58,66,60,.10)';
      ctx.lineWidth = 0.6;
      ctx.beginPath();
      ctx.moveTo(Math.random()*size, y);
      ctx.lineTo(Math.random()*size + 60, y);
      ctx.stroke();
    }
    ctx.restore();
  });
  return c;
}
```

**与现在噪点的区别**：有主方向（`angle`）、有断口（`gapLen`）、有深浅两色（凹痕 + 刀白边）、有交叉组。这四样缺一不可。

### 5.3 tone mapping

```js
// 木刻要硬切，不要 ACES 的柔
renderer.toneMapping = THREE.NoToneMapping;
renderer.outputEncoding = THREE.sRGBEncoding;
// 曝光靠材质颜色与光强控制，不靠 toneMappingExposure
```

改完后画面会变"硬"——黑更黑、白更白。如果过曝，降主光强度（1.6 → 1.3），不要加回 ACES。

### 5.4 印刷错位层（成本最低的"版画感"）

```js
// 在 canvas 上叠一个 1px 偏移的同源副本
const offsetLayer = renderer.domElement.cloneNode();  // 不行，WebGL canvas 不能 clone
// 替代：CSS 叠一层
const printOffset = document.createElement('div');
printOffset.style.cssText = `
  position:fixed; inset:0; pointer-events:none; z-index:3;
  background:inherit; mix-blend-mode:multiply; opacity:.05;
  transform:translate(1px,1px); filter:contrast(1.2);
`;
// 更实际的方案：用 canvas 的 toDataURL 做一次快照叠层（每 10 帧更新一次，成本可控）
```

**更省事的等效做法**：给整个 canvas 加 `filter: contrast(1.08) saturate(0.9)` + 1px 的 `text-shadow` 风格偏移——纯 CSS，零成本，视觉上已经能读出"印的"。

## 七、优先级（时间不够时砍什么）

**半天版（3 小时，收益 70%）**
1. F1 `flatShading: true`（10 min）
2. F2 降段数（1 h）
3. F4 改 NoToneMapping（15 min）
4. F3 刀痕替换（1.5 h）

**一天版（再加雪原）**
5. S1 + S2 + S3（3.5 h）—— 解决风格分裂
6. S6 全局纸纹（30 min）

**两天版（完整）**
7. F5 前景遮挡
8. S5 雪面块面化
9. E1/E2 余烬
10. 印刷错位层

**明确不做**
- ❌ 不做 PBR 回归（木刻是终点）
- ❌ 不加 bloom（会毁掉硬边）
- ❌ 不做 DOF（用雾分层）
- ❌ 不做角色骨骼动画（剪影 + 微动足够）

## 八、一句话

**木刻的"木"不在颜色，在块面与刀痕**：颜色已经对了（五阶灰 + 琥珀），但 `flatShading` 没开、段数没降、刀痕是噪点——所以现在只是"灰色的圆"，还不是"刻出来的"。

**雪原是主入口，却还是旧风格**——这是比任何细节都大的问题：用户第一眼看到的不是木刻。
