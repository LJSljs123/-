# 用户试用记录（模板 + 记录区）

用途：答辩必被问「给谁用过」。**只记录真实完成的测试，不补写、不模拟。**

建议样本：6 位未参与制作的成年人（同学、家人、老师均可），至少 2 位不熟悉抗战史。

---

## 任务设计（每位受试者做 3 件事，全程不提示）

| # | 任务 | 观察点 |
|---|---|---|
| T1 | 「找到童长荣牺牲那一条记载，打开它的原文出处」 | 是否找到、用时、卡在哪一步 |
| T2 | 「这条记载有几种不同的日期说法？分别是谁记的？」 | 能否读懂「主张甲/乙」与精度标注 |
| T3 | 「第 7 幕发生了什么？画面里为什么没有人？」 | 是否注意到空台、是否理解「不重演袭击」的设计 |

## 记录纪律

1. **不提示**。受试者问「点哪里」时只回答「你觉得该点哪里」。
2. **记录原话**，不要转述成结论。
3. 失败的样本同样记录——失败比成功更有信息量。
4. 涉及真人时不留姓名，用 U1–U6 编号。
